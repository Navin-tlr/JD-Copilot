## 🟠 Evidence Discipline
- Every insight backed by structured metrics or JD text.
- Missing data called out explicitly (“No evidence for X in snippets provided”).
- Structured results act as the spine; JD context provides muscle.

## 🟠 Testing Checklist (Visual)
1. Ask identical query twice → expect different layouts.
2. Compare a simple query vs a deep one → observe change in depth and section quantity.
3. Run hybrid query → verify structured stats sit alongside JD-driven narrative.
4. Inspect tone → dry wit, strategic clarity, zero fluff.
